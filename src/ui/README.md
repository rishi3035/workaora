# UI (design system)

Reusable building blocks that every feature shares: buttons, inputs, cards, dialogs and so on.

Rules:

- Components here know nothing about the database or about any single feature.
- Colours, sizes and spacing come from the design tokens, never one-off values.
- Every component must work with a keyboard, in light and dark, at phone width.

The components are added in Phase 1, step 1.6, once the visual direction is chosen.
